# With U

[English](README.md) | [Português](README.pt-BR.md) | [Русский](README.ru.md) | [简体中文](README.zh-CN.md)

Приватная комната для двух человек, где можно делиться вкладкой браузера, экраном или только звуком. Медиа передаётся напрямую через WebRTC, а сервер Node.js управляет комнатой, подключением, чатом и автоматическим переводом.

## Возможности

- Приватные комнаты с шестизначным кодом
- Режимы «экран и звук», «только экран» и «только звук»
- Временный чат в реальном времени
- Перевод на язык, выбранный каждым участником
- Интерфейс на португальском, русском, английском и упрощённом китайском
- Адаптивный интерфейс для компьютеров и телефонов
- Закрытие комнаты после выхода ведущего

## Локальный запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`, создайте комнату и отправьте приглашение.

## Использование

1. Вверху выберите язык входящих сообщений.
2. Нажмите **Создать комнату** и скопируйте приглашение.
3. После подключения гостьи выберите режим трансляции.
4. Нажмите **Начать трансляцию**.
5. В Chrome или Brave выберите вкладку и включите передачу её звука.

У бесплатного переводчика есть суточный лимит. Если перевод недоступен, будет доставлен исходный текст. Сообщения отправляются внешнему сервису перевода для обработки.

## Продакшен

Вне `localhost` требуется HTTPS. Для надёжной связи создайте учётную запись Metered Open Relay и добавьте в Render переменную окружения:

```text
METERED_TURN_API_URL=https://YOUR_APP.metered.live/api/v1/turn/credentials?apiKey=YOUR_API_KEY
```

Сервер получает временные данные `iceServers`, не раскрывая URL API в браузере или репозитории. Если переменная отсутствует, приложение использует Google STUN.

Проект не обходит DRM. Транслируйте только разрешённый контент.
