# For U

[English](README.md) | [Português](README.pt-BR.md) | [Русский](README.ru.md) | [简体中文](README.zh-CN.md)

一个供两人使用的私人房间，可以共享浏览器标签页、屏幕或仅共享音频。媒体通过 WebRTC 直接传输；Node.js 服务器负责房间、连接、聊天和自动翻译。

## 功能

- 使用六位邀请码的私人房间
- 支持“屏幕和音频”“仅屏幕”和“仅音频”
- 临时实时聊天
- 根据每位参与者选择的语言翻译消息
- 支持葡萄牙语、俄语、英语和简体中文界面
- 适配电脑和手机
- 主持人离开时关闭房间

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`，创建房间并发送邀请链接。

## 使用方法

1. 在页面顶部选择接收聊天消息的语言。
2. 点击**创建房间**并复制邀请。
3. 访客加入后选择直播模式。
4. 点击**开始直播**。
5. 在 Chrome 或 Brave 中请选择标签页并启用标签页音频共享。

免费翻译服务有每日配额。如果翻译不可用，系统会发送原始消息。聊天文本会发送到外部翻译服务处理。

## 生产环境

在 `localhost` 之外共享屏幕需要 HTTPS。为了在严格 NAT 或防火墙网络中可靠连接，请在 `public/app.js` 的 `iceServers` 中配置 TURN 服务器；仅使用 STUN 无法覆盖所有网络。

本项目不会绕过 DRM。请仅共享您有权传播的内容。
